# mdadm — `hardware-mdadm`

`modules/features/hardware/mdadm.nix`. Option `hardware.mdadm`.

## What it sets, and why

Enabling it installs `mdadm` into `environment.systemPackages` and nothing
else. The array assembly itself lives in each host's
`_hardware-configuration.nix` (`mdadm` arrays defined from the disks),
generated by `nixos-generate-config` — this module only guarantees the
tool is present so those arrays can be managed (`mdadm monitor`,
rebuilds, spare-disk swaps) from a shell.

## Why the design

It's a one-line module because it's a marker: hosts that were set up with
software RAID (the fleet's disks are mdadm arrays) need the tool exposed;
hosts that aren't shouldn't carry it. The configuration stays where it
belongs — per-host hardware, not a feature.
